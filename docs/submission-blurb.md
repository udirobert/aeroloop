# 3-line blurb (submission)

AeroLoop is an agent that gets measurably better every time it runs: it forecasts London PM2.5, scores itself against real ground monitors, and rewrites its own strategy skill between runs — in git.
Across 13 real TrueForge sessions on two open-weight models it peaked at 87.03 — then, frozen against 24 unseen tasks, it scored 55.1, diagnosed its own overfitting, and rewrote its playbook to reach 63.65.
Every run is a verifiable session pinned to a commit the agent wrote — the agent edits itself, not us.
