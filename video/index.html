In a challenge called "an agent that gets
better every time it runs", every
submission shows a number going up.
This is the run where ours went down.
AeroLoop forecasts London PM two point
five.
It scores itself against real ground
monitors —
and between runs, it rewrites its own
playbook.
The skill file lives in git.
The agent writes the commits.
On eight tasks it learned the satellite
model under-reads the street, and settled
on one rule: multiply by one point two.
It scored eighty-seven.
So we froze the playbook and showed it
twenty-four forecasts it had never seen.
It scored fifty-five.
The rule that looked learned was just
overfit.
Then the agent did the thing the challenge
is actually about.
It read its own failures, diagnosed the
broken rule, and rewrote its strategy —
per-station uplifts, a traffic term, a
wind correction.
Nobody wrote that fix for it.
Next run: sixty-three point six.
On tasks it never tuned against.
Every run is a real TrueForge session,
pinned to a commit the agent wrote.
The playbook it edits is cloned from the
repo it ships in.
AeroLoop.

runs.
